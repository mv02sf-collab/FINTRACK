# FinTrack

Sistema de controle financeiro pessoal desenvolvido em Python.

## Objetivo

O FinTrack tem como objetivo auxiliar no gerenciamento de
finanças pessoais, permitindo registrar receitas, despesas,
acompanhar o saldo e analisar gastos.

## Tecnologias

- Python
- Git
- GitHub
